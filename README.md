# Bikini Quest

Dive into Bikini Quest, a fast-paced pixel adventure inspired by underwater chaos and retro platformers.

Explore colorful underwater worlds, unlock powerful abilities, defeat robotic enemies, collect shards and coins, and master advanced movement mechanics including double jumps, spin attacks, and wall jumps.

## Features

- Pixel-art retro style
- Multiple handcrafted levels
- Double Jump system
- Spin Attack ability
- Wall Jump mechanic
- Enemy AI and projectiles
- Coins & collectible shards
- Mobile touch controls
- Smooth camera and particle effects

## Controls

| Key | Action |
|------|--------|
| WASD / Arrow Keys | Move |
| Space / Z | Jump & Double Jump |
| X | Punch |
| C | Spin Attack |
| R | Summon Rocky |
| T | Throw Rocky |
